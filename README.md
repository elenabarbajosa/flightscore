# FlightScore

FlightScore is a long-haul flight search web app that ranks itineraries using adjustable price, stops, and duration preferences, with penalties for risky connections and long layovers.

## Requirements

- Node.js 20 or later
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

```bash
npm run build
npm run lint
npm run typecheck
```
